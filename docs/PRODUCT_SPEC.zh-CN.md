# 产品规格

## 问题

Agent 评测和 rollout 导出可能因畸形记录、超大单行、嵌入二进制数据或重试产生的重复负载而变得难以安全移动和审阅。通用 JSON 工具常常加载完整文档，也不会表达这些面向 rollout 的聚合风险。

## MVP 契约

`rollout_guard` 对用户明确指定的 JSONL 文件执行只读、离线、流式分析；输出文本、JSON 或 SARIF 汇总，不包含输入值和绝对路径。README 中的规则标识保持稳定。阈值只是策略，不代表产物一定恶意。

## 非目标

不扫描主目录、不递归、不上传、不删除、不修改、不脱敏、不转换、不重放、不做提示词语义分类、不猜测任意 base64，也不声称支持所有 Agent 框架。

## 资源边界

不缓存完整文件；每行最多保留配置上限外加一个字节。编码长度超过 8 MiB 的显式 data URL 只记为未检查，不执行解码。每类重复检测最多保留 250,000 个哈希；达到上限时明确报告饱和，不会默默声称检测完整。
